# OpenTweek linked journal 1.3.0

User-approved extension: calendar and feelings journal are two views of one local date with explicit references, private journaling, optional structured reflection and local assistance. No remote generation or personal reference-image content enters artifacts.

Seven reflection areas: situation (existing free text), thoughts, feelings, body, perspective, actions and afterwards; add an optional needs vocabulary. Context is selected explicitly, never inferred. Every field permits free input and skipping.

Drafts are independent of completed entries, locally persisted, restored on revisit and removed on explicit save/cancel. Task links follow moves, survive renames and detach without deleting private content. Recurrence links identify a specific date. External feed links show unavailable when source disappears. Task share/ICS excludes all journal fields. Full JSON backup deliberately includes completed private entries.

Android Preview uses distinct app.opentweek.preview sandbox and a disposable development signing identity. Preserve historical artifacts and original app data. Runtime microphone/wake quality remains unverified.

Verification: migrations, link lifecycle/undo, privacy, draft/save/cancel, selected local date near UTC boundary, mobile UI and APK identity/signature checks. Merge only into existing OpenTweek development base, never automatically into main. CI blocked by account billing is disclosed, not treated as a passing check.
