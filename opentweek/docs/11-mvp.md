# opentweek: объём версии 1.0

Актуальность: 27 сентября 2026 года.

## 1. Определение готовности

Версия 1.0 готова, когда подписанный APK из репозитория ставится на Android 7+, хранит задачи между запусками и показывает напоминание при закрытом приложении. Тот же код без изменений работает как PWA в браузере.

## 2. Что входит

- Неделя в линейку; выходные в одной колонке, отдельными колонками или скрыты; неделя начинается с любого дня (сценарии 1, 4).
- Перетаскивание мышью, пальцем и с клавиатуры между днями, списками и внутри дня (4).
- Месяц с перетаскиванием (4).
- Списки «Когда-нибудь» и календари без ограничения количества (7).
- Повторы: пресеты и своё правило с окончанием по дате или числу раз; отметка, пропуск и отвязка отдельного повтора (3).
- Карточка задачи: заметка, подзадачи, вложения, 9 цветов, время напоминания (2, 6).
- Напоминания: в браузере, пока вкладка открыта; на Android через `AlarmManager` на 30 дней вперёд, до 100 штук (2).
- Подписки на ICS (Google, iCloud, Outlook) только для чтения; на Android без CORS (5).
- Импорт и экспорт `.ics`, полный бэкап JSON вместе с вложениями (8).
- Шаринг задачи ссылкой без сервера, на Android через системное меню (9).
- Русский и английский интерфейс, темы, бумага, размер текста, поиск, горячие клавиши, печать, отмена удаления.
- Android: свайп между неделями, кнопка «назад», системное «Сохранить как».

## 3. Что сознательно не входит

- Синхронизация между устройствами — не-цель PRD, ADR-0009.
- Двусторонняя синхронизация с Google Calendar — нужен OAuth-клиент и сервер для токенов.
- Push-напоминания в браузере при закрытой вкладке — нужен push-сервер.
- Виджет на домашний экран Android — отложен в 1.1 (T-110).
- Публикация в Google Play — не-цель PRD.

## 4. Приоритетные сценарии

Порядок реализации, уже пройденный:

1. Запись задачи в день и перетаскивание.
2. Повторы и отметка отдельного повтора.
3. Карточка задачи: подзадачи, заметка, цвет.
4. Локальное хранение и бэкап.
5. ICS-подписки.
6. Android-оболочка с нативными напоминаниями.
7. Русский интерфейс.

## 5. Упрощения, за которые платим позже

| Долг | Чем грозит | Когда возвращать |
|---|---|---|
| Все задачи календаря грузятся в память целиком (`useTasks`) | Замедление на 10k+ задач | Когда задач станет больше 5000 или открытие недели превысит 200 мс |
| Напоминания на Android планируются на 30 дней и не более 100 штук | Дальние напоминания появятся только после открытия приложения | Если пользователь месяц не открывает приложение — сценарий маловероятен |
| Порядок задач — числа с плавающей точкой без нормализации | Точность теряется после примерно 50 вставок подряд в одно место | При первом замеченном «прыжке» строки; нормализация в T-112 |
| Ключ подписи в репозитории | Любой может выпустить «обновление» | Перед публикацией вне личного использования, ADR-0006 |
| Нативный мост не покрыт автотестами на устройстве | Регрессии в Java видны только вручную | 1.1, T-103 (инструментальный смоук через `adb`) |
| `android.jar` API 23: API новее вызываются через рефлексию | Ошибка в имени метода не ловится компилятором | При переходе на более новый `android.jar`, ADR-0005 |
