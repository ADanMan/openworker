# ADR-0009: Синхронизация отложена до 2.0

Дата: 27 сентября 2026 года
Статус: Proposed

## Контекст

Tweek синхронизирует устройства и даёт общие календари. У opentweek сервера нет. Перенос между устройствами сейчас идёт только через бэкап JSON.

## Рассмотренные варианты

- Yjs + `y-indexeddb` + свой `y-websocket` — CRDT, MIT, самохостинг / нужен свой сервер, миграция модели из Dexie;
- PowerSync или ElectricSQL — зрелая синхронизация / нужен Postgres и сервис;
- Файл бэкапа в облачной папке (Google Drive, Nextcloud) с merge по `updatedAt` — нет сервера / конфликты разрешаются «последний победил», нет реального времени;
- Triplit — AGPL-3.0, несовместим с MIT-проектом; Replicache — проприетарные условия.

## Решение

В 1.x синхронизации нет. На этапе 3 выбор между Yjs и файлом в облачной папке по критерию из roadmap.

## Последствия

Положительные: 1.x остаётся без инфраструктуры.
Отрицательные: два устройства расходятся; общий календарь невозможен.
Что станет сигналом пересмотреть решение: второе устройство в ежедневном использовании — этап 3 начинается.
