# ADR-0011: локальная русская диктовка и отдельный дневник

Дата: 3 октября 2026. Принято для 1.2.0; заменяет голосовую архитектуру ADR-0010.

Дневник — отдельная таблица Dexie v2, не задачи. Vosk Android 0.3.75 + JNA 5.18.1 распознают PCM на устройстве. Русская модель small-ru-0.22 загружается по явному действию, проверяется SHA256 и устанавливается атомарно. Сырые записи не сохраняются. Text → editable draft → explicit save; настроение только самооценка пользователя.

Отвергнут системный RecognizerIntent/Web Speech: они не гарантируют отсутствие внешнего распознавания. Whisper multilingual остаётся альтернативой для будущего сравнения качества/ресурсов; Vosk выбран как меньшая Android-модель с потоковым API и готовыми JNI-библиотеками. Никакого облачного fallback.

Первый выпуск — foreground-only. «Эй» и «твик» найдены в реальном словаре, но детектор не прошёл оценку ложных срабатываний; wake toggle не добавляем. Настоящий фон требует отдельной microphone foreground service с явным opt-in и уведомлением, тестирования ограничений Android и энергопотребления.

Сборка требует SDK35/JDK17 и упаковки JNI. Оставлены package/origin/min24/target34. Отдельная debug-подпись не совместима с обновлением чужой подписи; release-signing не выполняется. Инструкция и пределы проверки: [44-local-journal](../44-local-journal.md).
