# ADR-0007: Шаринг задачи без сервера, через фрагмент URL

Дата: 27 сентября 2026 года
Статус: Accepted

## Контекст

Tweek умеет делиться задачей по ссылке. У opentweek нет сервера.

## Рассмотренные варианты

- Хранить общие задачи на сервере — короткие ссылки / нужен сервер;
- Кодировать задачу в `#share=` (deflate-raw + base64url) — фрагмент не уходит на сервер при открытии ссылки / длинные ссылки, нет обновлений после отправки.

## Решение

`src/lib/share.ts`: `SharePayload` версии 1 сжимается `CompressionStream('deflate-raw')` и кладётся во фрагмент. Получатель видит диалог и сам решает, добавлять ли задачу. На Android без `VITE_PUBLIC_URL` отправляется только текст: origin `app.opentweek.local` снаружи не открывается.

## Последствия

Положительные: ноль инфраструктуры; содержимое не попадает в логи хостинга.
Отрицательные: ссылка — снимок, а не живая задача; длина растёт с заметкой.
Что станет сигналом пересмотреть решение: этап 3 (синхронизация) — тогда общие календари заменят снимки.
