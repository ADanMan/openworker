# ADR-0001: Данные только на устройстве, IndexedDB через Dexie

Дата: 27 сентября 2026 года
Статус: Accepted

## Контекст

Нужен планировщик без аккаунта, работающий офлайн. Сервера нет и поддерживать его некому. Данных немного: сотни или тысячи задач, вложения до единиц мегабайт.

## Рассмотренные варианты

- `localStorage` — просто / лимит около 5 МБ, синхронный API, нет бинарных данных для вложений;
- IndexedDB напрямую — без зависимостей / многословный API, нет живых запросов;
- Dexie 4 + `dexie-react-hooks` — живые запросы `useLiveQuery`, транзакции, Apache-2.0 / зависимость около 30 КБ gzip;
- RxDB, PowerSync, ElectricSQL — готовая синхронизация / нужен сервер или платные плагины, избыточно для 1.x.

## Решение

Хранить всё в IndexedDB через Dexie; схема в `src/db.ts`, версия 1.

## Последствия

Положительные: работает офлайн; реактивный UI без стейт-менеджера; вложения хранятся как `Blob`.
Отрицательные: удаление приложения или очистка данных сайта стирает всё; синхронизации нет.
Что станет сигналом пересмотреть решение: появление второго устройства в ежедневном использовании (этап 3), либо более 10k задач с открытием недели дольше 200 мс.
