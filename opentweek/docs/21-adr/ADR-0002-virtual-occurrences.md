# ADR-0002: Повторяющаяся задача хранится одной записью

Дата: 27 сентября 2026 года
Статус: Accepted

## Контекст

Повторы бывают бесконечными (`FREQ=DAILY` без `COUNT`). Нужно отмечать выполнение и пропуск отдельного повтора и перетаскивать один повтор на другой день.

## Рассмотренные варианты

- Материализовать копии на N недель вперёд — простые запросы / нужен фоновый досоздатель, правка серии превращается в правку N записей;
- Одна запись с `rrule` + `exdates` + `doneDates`, повторы вычисляются на видимый диапазон — одна правка меняет серию, бесконечные серии бесплатны / порядок строк у повторов общий для всех дней серии.

## Решение

Одна запись `Task` с `rrule` (тело RRULE без `DTSTART`, начало серии — `date`), `exdates` и `doneDates`. Функция `expand()` в `src/lib/recurrence.ts` строит строки `Item` для видимого диапазона. Перетаскивание повтора на другой день отвязывает его: в серию добавляется `exdate`, создаётся самостоятельная задача (`detachOccurrence`).

## Последствия

Положительные: серия правится одной записью; экспорт в ICS даёт `RRULE` и `EXDATE` без преобразований.
Отрицательные: порядок повтора внутри дня одинаков для всех дней серии; при перенумерации повторы не трогаются (`interleaveOrders` в `src/actions.ts`).
Что станет сигналом пересмотреть решение: понадобятся разные подзадачи или заметки у разных повторов одной серии.
